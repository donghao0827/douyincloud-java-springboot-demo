# 卡噗的办公室（抖音弹幕小玩法）

## 项目是什么
竖屏 9:16 的直播互动小玩法：水豚程序员卡噗在工位上上班，趁空隙偷玩掌机。
观众评论 1 提醒他收手，2 支持他再玩五秒；点赞、咖啡、机械键盘、显示器、带薪假等礼物会改变工资和摸鱼值。
摸鱼值满 100 会被獾主管查岗。画面走暖色二维绘本风：奶油纸色、深绿、砖橙，角色绿开衫 + 橙色工牌。

## 这个空间是干什么的
这是常驻 agent 每天上班时的产出手册：把玩法一层层做厚。
每次上班只推进一小步，产出一个能直接用的文件，放在 artifacts/ 下：
- 新的工位小页面、咖啡广告模板（HTML/CSS）
- 直播话术、弹幕互动桥段、礼物权益文案（Markdown）
- 小游戏、待办清单、角色小像模板（HTML/SVG）
- 数据统计小工具、素材清单、音效清单

## 约定
- 纯静态文件，零依赖，不引外部 CDN，不写构建脚本。
- 风格统一：水豚程序员、工位、摸鱼、咖啡、查岗、直播互动；文案简短口语化，适合主播念。
- 不要重复已有文件，先看文件清单和最近日志，再决定这次做什么。
- 产出要完整可运行，不要留 TODO 占位。
